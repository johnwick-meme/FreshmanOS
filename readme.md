# FreshmanOS

> Your college. Your resources. Your community.

FreshmanOS is an open-source platform designed to help college freshmen navigate academics, campus life and student community.

## Features

- 📚 Academic Hub
- 🗺️ Campus Guide
- 👥 Student Hub
- 🎉 Events
- 🔍 Lost & Found
- 🆘 Help & Support

## Built By

A team of first-year CSE students.
